# Salut, moi c'est Aron 👋

**Fondateur de [VOKYVO](https://vokyvo.com) — Développeur full-stack autodidacte 🇧🇫**

Je construis **VOKYVO**, une super-app africaine qui réunit messagerie, visioconférence, assistant IA, cours intelligents et actualités dans une seule plateforme. Tout est pensé pour les réalités de l'Afrique de l'Ouest.

---

## 🚀 Ce que je construis

### [VOKYVO](https://vokyvo.com) — La super-app africaine
Plateforme de communication intelligente pour l'Afrique de l'Ouest.

- 💬 Messagerie instantanée (privé + groupes)
- 📹 Visioconférence jusqu'à 5 participants
- 🤖 Assistant IA intégré (chat + mode Expert Maths)
- 📚 Cours intelligent (OCR + TTS + Q&A)
- 📰 Actualités en 31 rubriques
- 📱 Disponible sur Android (APKPure)

**Stack :** Python · Django · DRF · React 19 · TypeScript · Capacitor · PostgreSQL · Redis · Daphne · WebSocket · Nginx · Cloudflare

🔗 [vokyvo.com](https://vokyvo.com) · [Mon parcours](https://vokyvo.com/aron-vokouma)

## 🎯 Ma vision

> Le numérique africain mérite ses propres solutions, conçues par ceux qui les utilisent.

Je crois que les meilleures réponses aux problèmes africains viennent d'Africains qui vivent ces problèmes au quotidien. C'est pourquoi je construis des outils pensés pour nos réalités : économes en données, rapides sur téléphones modestes, adaptés aux connexions réelles du continent.

Mon ambition avec **VOKYVO LABS** est de démontrer qu'il est possible, depuis l'Afrique, de construire des produits numériques de classe mondiale.
